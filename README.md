# configkit

configkit 是极简、易用、人体工程学的配置文件框架。

configkit is a minimal, friendly, ergonomic configuration-file framework.

- **中文文档**：[README.zh.md](README.zh.md) · 参与开发 [contribute.zh.md](contribute.zh.md)
- **English docs**: [README.en.md](README.en.md) · Contributing [contribute.en.md](contribute.en.md)

```sh
raco test tests/        # 测试 / run the tests
./build-docs.sh         # 手册（需完整 Racket）/ the manual (needs full Racket)
```

运行 configkit 只需 `base` + `sandbox-lib`；文档不随安装构建，见
[build-docs.sh](build-docs.sh)。

Running configkit needs only `base` + `sandbox-lib`; docs are not built at
install time — see [build-docs.sh](build-docs.sh).
